コントローラー（PC本体の USB の口のまとまり）→ ハブ → 機器 の順に並べています。赤い枠は、くり返し外れている機器です。

つないだ・外したときの音

Windows が鳴らす「つないだ」「外した」「失敗した」の3つの音です。消すと、ほかの USB 機器でも鳴らなくなります。

今：確かめています

省電力で USB が切れる設定（PC 全体）

電源プランの「USB のセレクティブ サスペンド」です。有効だと、使っていない USB 機器の電源を Windows が切ることがあります。機器ごとの設定は、一覧の「くわしく・操作」から変えられます。

今：確かめています

自分でつけた名前（names.json）と履歴（history.jsonl）を保存しています。
